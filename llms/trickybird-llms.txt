# TrickyBird

> TrickyBird is a private web proxy that opens sites blocked on a network or in a region, in a normal browser tab, no install. It rewrites the page as it passes through, so wherever TrickyBird has to carry the target site's address it carries it encoded rather than spelled out. TrickyBird has no account and keeps a small access log for at most 48 hours. The log writes one line for every request the proxy handles on your behalf, including the ones it turns away, so it holds a shortened form of your IP address and the hostname of each site or service a page loads from. The log never holds the specific pages you open, page contents, or messages.

## Learn

- [Learn hub](https://trickybird.com/learn): Short, honest explainers: how a web proxy works, how it differs from a VPN, what it hides, and what it cannot do.
- [What is a web proxy?](https://trickybird.com/learn/what-is-a-web-proxy): A web proxy opens 1 blocked site at a time in a normal browser tab and hides your IP from that site. It is not a VPN, and that is exactly why it works where you cannot install one.
- [Web proxy vs VPN: which one do you actually need?](https://trickybird.com/learn/web-proxy-vs-vpn): Use a VPN when you control the device and want every app covered; use a web proxy when the device is locked down and you only need 1 blocked site to open.
- [What is a DNS or WebRTC leak?](https://trickybird.com/learn/what-is-a-dns-and-webrtc-leak): A DNS leak shows where you are going, and a WebRTC leak can show who you are, so test both yourself rather than trusting any single promise.
- [Is using a web proxy legal or illegal?](https://trickybird.com/learn/is-using-a-proxy-legal): In most places, using a web proxy to reach a public site is legal; the limit you actually hit is usually your network’s own policy, not the law.
- [Are free web proxies safe?](https://trickybird.com/learn/are-free-web-proxies-safe): Some free web proxies inject ads or strip HTTPS, so the honest move is to check whichever one you use rather than take it on trust, ours included.
- [What is a proxy server?](https://trickybird.com/learn/what-is-a-proxy-server): A proxy server is any intermediary that makes requests for you; the type depends on who it works for and where its address comes from. TrickyBird is the web proxy kind, opened in a browser tab with nothing to install.
- [Why is a site blocked on your network?](https://trickybird.com/learn/why-networks-block-sites): A network blocks a site to enforce its own policy, not because the site is banned everywhere. A web proxy can reach a public site the network blocks, but not a paywall, a login, or a service’s regional licensing.
- [Can your ISP see that you are using a web proxy?](https://trickybird.com/learn/can-my-isp-see-a-web-proxy): Your ISP can see that you connect to TrickyBird, so it can tell you use a web proxy. What it cannot see is the site you open through it, and that is the honest line: a web proxy hides where you go, not that you went.
- [Does a web proxy work on your phone?](https://trickybird.com/learn/does-a-web-proxy-work-on-mobile): A web proxy runs in the mobile browser you already have, so it opens a blocked site on your iPhone or Android with nothing to install. That is exactly why it works on a phone where a VPN app cannot.
- [Does incognito mode get past a blocked site?](https://trickybird.com/learn/does-incognito-mode-unblock-websites): Incognito mode clears what your own device remembers, not what the network blocks, so it does not unblock a site. A web proxy fetches the page from a different address, and that is what actually gets past a network block.
